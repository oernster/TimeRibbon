Changelog

What's new

Recent releases have settled the ribbon into each desktop: its clocks now run west to east in the same order as the sun map, macOS keeps it in the menu bar alone and a Linux restart no longer hangs on it. Before that, TimeRibbon moved onto ribbonkit, the library it shares with WeatherRibbon, so two ribbons on one desktop never land on each other. Earlier releases brought resizing by hand, a see-through ribbon, the sun map, ten colour schemes, an update check and TimeRibbon itself on macOS and Linux under its new name.

v2.10.0

The clocks run in the same order as the map

  • The ribbon orders its clocks west to east by where their cities sit on the sun map, so the cells and the map's red dots read the same way round
  • It used to start at London and run east, putting the Americas at the end while the map drew them on the left
  • A clock with no city of its own, such as UTC, stands where its offset would put it on the map; across the date line the map decides, so Tonga comes before Hawaii
  • The order follows the place rather than the hour: Madrid keeps Paris's time but sits west of London
  • A digital clock's place, time and date now sit in the middle of its cell, as an analogue clock's already did
  • Your settings file is read and written as before; the clocks take their new places with nothing to change
v2.9.0

At home in the menu bar; clean restarts on Linux

  • On macOS TimeRibbon lives in the menu bar alone: no Dock icon, no place in the app switcher and no tile left in the Dock's recent apps at each launch
  • On macOS it now quits when the system asks at log out, restart or shut down instead of holding them up; closing the ribbon yourself still leaves it in the menu bar
  • On Linux a restart with the ribbon running often left GNOME Shell hung. TimeRibbon now hears the shutdown coming and leaves at once: in testing 6 of 8 restarts had hung, after the change 3 of 3 were clean
  • To hear that notice the Flatpak asks for one more permission, talking to logind; without it TimeRibbon carries on as before
  • The Flatpak no longer flashes a large black window over the screen at sign-in
v2.8.0

Position never offers a move that does nothing

  • A Position choice that would leave the ribbon exactly where it stands, beside another ribbon, is now greyed in both menus and in Settings
  • A race at start between the ribbon's window and Wails, found by the race detector, is fixed; so is the same race in the Windows setup program, whose decisions are now covered by tests
  • More of the ribbon now comes from ribbonkit, the library shared with WeatherRibbon; nothing about how TimeRibbon looks or behaves changes
v2.7.0

Built on ribbonkit; two ribbons never land on each other

  • TimeRibbon is now built on ribbonkit, an open source library shared with WeatherRibbon, so a fix to how a ribbon behaves reaches both at once; TimeRibbon keeps only what makes it a clock
  • A ribbon being placed moves along its edge to the nearest free space, then tries the opposite edge; a ribbon already in place never moves because another arrived, moved or grew
  • With the ribbon in open space, away from every edge, the sun map keeps the side it was on while there is room there, remembered across restarts
  • Dragging between displays at different scales no longer leaves the map drawn on one side while the window was shaped for the other
  • The documents now say that TimeRibbon shows in the Dock on macOS, as it always had on a real Mac
  • The Flatpak asks for access to one private folder, ribbonkit, in your session's runtime folder; your settings gain one key, pullOutSide
v2.6.0

Smooth resizing; opacity that fades only the background

  • Dragging the corner grip grows and shrinks the ribbon from its top-left corner, so the corner stays under the pointer; the size follows it pixel by pixel on Windows, macOS and Linux
  • The Opacity slider fades only the ribbon's background, each dial's face and the unpinned tab; the times, dates, hands and sun map stay solid. Settings and the other panels are always fully opaque
  • On Windows a lowered opacity now shows the desktop behind the ribbon rather than grey
  • On macOS and Linux the spare area beside a short ribbon with its map out now answers a right-click and a drag as the clocks do
  • On GNOME a first launch opens against the right edge rather than the top-left corner
  • Settings opens at the right height for its content
v2.5.0

Your settings are safer

  • A settings file that is there but cannot be read raises a notice and nothing is saved over it, so your clocks are never replaced by the defaults
  • Every damaged settings file kept aside now gets a name of its own, so no kept copy is lost
  • A settings file with a byte order mark, as Notepad or older PowerShell save it, now reads; two clocks given the same id by hand are told apart
  • Every place behind UTC now comes after every place level with or ahead of it
  • An update's page and download are taken only as secure GitHub addresses, so an update offer cannot send your browser anywhere unexpected
v2.4.0

The ribbon fits on a scaled KDE desktop

  • On a Linux desktop scaled to a fraction, such as KDE Plasma at 150 percent, the ribbon no longer comes up cut off and Settings keeps its full layout
  • The ribbon is shown only once the page has sized it, so it no longer stays cut off until a clock next changes
  • On Linux the web view's hardware acceleration is now off, as Wails intends
  • cleanup_flatpak.sh removes the folder a failed Flatpak build leaves behind
  • DECISIONS-TRADEOFFS.md records every deliberate choice the product makes with what it gains and costs
v2.3.2

No more blank window with NVIDIA on Linux

  • With NVIDIA's own driver on Linux the window could open as a plain dark panel. TimeRibbon now turns off WebKitGTK's DMABUF renderer before its window opens, keeping your own WEBKIT_DISABLE_DMABUF_RENDERER if you set one
  • The README now says to choose Exit from the menu before installing a newer release on Linux, since a copy left running carries on with the old one
v2.3.1

Linux build fixes

  • Fixes to the Linux build and cleanup scripts
v2.3.0

Resize by hand; a see-through ribbon

  • A grip in the ribbon's corner resizes the clocks from 75 to 200 percent of the size chosen in Settings; double-click it to return them to their own size
  • A new Opacity slider in Settings fades the window as low as 20 percent, so the ribbon can sit over your work without hiding it
  • Settings now offers every choice the menus do, in columns side by side; it opens as tall as what it holds and scrolls only on a display too short for it
  • The place search matches the start of a word, listing cities whose names begin with what you typed first
  • The sun map's arrow has a lane of its own, so it no longer covers a clock
  • Clocks are as wide as the widest time and date they can show in your machine's font, so dates are no longer cut short
  • An unpinned ribbon with the sun map on draws whole every time it opens, keeps its place across a restart and shrinks a second after the pointer leaves
v2.2.0

A sun map, date formats and a ribbon that waits as a tab

  • Tick Sun map and a world map slides out from the ribbon, lit where it is day and dark with city lights where it is night, each clock's city marked in red; the pictures are NASA's Blue Marble and Black Marble, built in so nothing is fetched
  • Settings gains a Date format choice: the weekday with the month in words, day first or month first; a short weekday with the date in numbers, day, month or year first
  • Untick Pin ribbon and a ribbon against an edge shrinks to a thin tab; rest the pointer on it and the ribbon opens without taking the keyboard from what you are typing in
  • Launching TimeRibbon while it runs now shows or hides the ribbon, so one Stream Deck button can bring the clocks up and put them away
  • The donate button's message no longer names Windows on macOS and Linux
v2.1.0

Ten colour schemes and an update check

  • Amber, Ruby, Indigo, Berry and Contrast join the first five schemes, each with a light and a dark side that follow the theme
  • Ocean is now deep teal with aqua text; Neon gains a light side
  • The whole clock shows when Windows text is enlarged
  • A few seconds after it starts and once a day, TimeRibbon asks GitHub for the latest release and offers Download, Skip this version or Later; Help gains Check for updates
  • This is TimeRibbon's one network request: it sends nothing about you or your clocks and never installs anything by itself. The Linux Flatpak gains network access for it alone
v2.0.0

TimeRibbon on macOS and Linux, under a new name

  • TimeRibbon now runs on macOS (Apple Silicon with macOS 12 or later, signed and notarised by Apple) and on Linux (a Flatpak for your own account), doing everything the Windows ribbon does
  • TimeStrip is now TimeRibbon, renamed over a trademark concern. It is a fresh install that carries nothing over, so uninstall TimeStrip first or both will run
  • A new Position submenu centres the ribbon against an edge of its display; each orientation has a home edge it opens against
  • A new Size choice draws every clock large or small
  • A new Colour submenu offers five schemes: Classic, Neon, Ocean, Sunset and Forest
  • Style and Orientation move into submenus of both menus; Settings keeps its title and Close button in view while the rest scrolls
